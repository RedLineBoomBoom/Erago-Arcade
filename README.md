## 🌟 Key Features

### 🎰 1. Roulette & Slot Machine Engine
- Spin through **200 hand-curated game cartridges** ranging from 1978 arcade classics to modern indie GOTY masterpieces.
- Dynamic slot reel animations, sound synthesis, and real-time trivia card displays with CRT scanline effects.

### 📚 2. 200 Comprehensive Trivia Cartridges
Organized cleanly into 5 historical eras:
- **The Genesis Era** (`t-01` – `t-40`): Foundational industry icons (*Mario, Zelda, DOOM, Half-Life, God of War*).
- **Arcade & 8/16-Bit Epoch** (`t-41` – `t-80`): *Space Invaders, Pac-Man, Mega Man 2, Chrono Trigger, EarthBound, Final Fantasy VI*.
- **3D Pioneers & 90s PC Revolution** (`t-81` – `t-120`): *StarCraft, Diablo, Crash Bandicoot, Age of Empires II, Resident Evil 2, GoldenEye 007*.
- **Golden 2000s Console Wars** (`t-121` – `t-160`): *World of Warcraft, Halo 2, GTA III, Kingdom Hearts, Dead Space, BioShock*.
- **Modern Masterpieces & Indie Legends** (`t-161` – `t-200`): *Minecraft, Hollow Knight, Celeste, Hades, Stardew Valley, Baldur's Gate 3*.

Each cartridge features:
- In-depth development lore & verified facts
- Mindblown rating (70% - 99%) & rarity tiers (Common, Rare, Epic, Legendary, Mythic)
- Interactive 4-choice trivia quizzes with immediate feedback and historical explanations

### 🏛️ 3. Museum Exhibit Wings & Dossier Inspection
- **Exhibit A (Left Wing)**: Character Spotlight featuring iconic video game heroes, origin stories, quotes, and badges.
- **Exhibit B (Right Wing)**: Game Artifact Exhibit featuring physical media specs, ROM serial numbers, developer studios, and box art.
- **Modal Inspection**: Click any exhibit or card to inspect high-definition classified dossiers and lore snippets.

### 👾 4. Retro Mini-Games & Boss Battle
- **Boss Battle Arena**: Turn-based retro arcade battle. Answer trivia questions correctly to charge your attack meter and defeat boss titans!
- **Mini-Game Arcade Corner**: Multi-game arcade hub featuring reflex challenges, memory puzzles, and retro mini-games.

### 💾 5. Retro DOS Terminal
- Access secret cheat codes, hidden easter eggs, developer logs, and terminal hacks straight out of a 90s MS-DOS prompt.

### 🎵 6. 8-Bit Web Audio Jukebox
- Procedural Web Audio API sound engine generating authentic chiptune clicks, coin inserts, retro victory fanfares, and synth music tracks.

### 🗃️ 7. Card Binder & Collector's Album
- Filter, search, and browse your entire 200-card collection by Era, Rarity Tier, Platform, or Developer.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS v4 + Custom Neo-Brutalist Arcade Design System
- **Icons**: Lucide React
- **Audio Engine**: Pure Web Audio API Synthesizer (Zero heavy external sound files)
- **Tooling**: Vite + Oxlint

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed

### Installation

```bash
# Clone repository
git clone https://github.com/RedLineBoomBoom/Erago-Arcade.git

# Enter project directory
cd Erago-Arcade

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production

```bash
npm run build
```

The production output will be generated inside the `dist/` directory.
